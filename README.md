# ⚔️ 永恒地牢 v2.0 - Eternal Dungeon

一个用 Java Swing 编写的地牢探险 RPG 游戏。

## ✨ 功能特性

- ✅ 登录注册系统
- ✅ 多层地牢探险
- ✅ 7种怪物（史莱姆、骷髅兵、蝙蝠、哥布林、狼人、法师、巨魔）
- ✅ 宠物系统（火龙、麒麟、凤凰、独角兽）
- ✅ 装备系统（开发中）
- ✅ 技能系统（开发中）
- ✅ 商店系统（开发中）
- ✅ 背包系统（开发中）
- ✅ 升级系统
- ✅ 暴击系统
- ✅ 小地图
- ✅ 战斗日志

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| **WASD / 方向键** | 移动 |
| **空格** | 攻击附近的怪物 |
| **底部按钮** | 背包/商店/宠物/技能 |

## 🚀 快速开始

### 方法一：双击启动
直接双击 `启动游戏.bat`

### 方法二：命令行启动
```bash
cd src
javac -encoding UTF-8 EternalDungeon.java
java EternalDungeon
```

## 🎯 游戏目标

探索地牢，击败怪物，收集装备，不断升级，挑战更深层的地牢！

## 🔄 访问方式

游戏支持多种访问方式：
1. **本机访问** - 直接运行，无需网络
2. **局域网访问** - 同一WiFi下其他设备可访问（开发中）
3. **公网访问** - 通过内网穿透，全球可访问（开发中）
4. **暗网访问** - 通过Tor隐藏服务，匿名访问（开发中）
